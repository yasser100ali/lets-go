# Let's Go

iOS app: a live map of things to do within walking distance, home kitchens selling food, and Wren, an AI guide. See README.md for what exists.

## Stack
- iOS 26+, Swift 6 (default MainActor isolation), SwiftUI, SwiftData, MapKit, FoundationModels.
- Project generated by XcodeGen from `ios/project.yml`. Sources are a synced folder — a new `.swift` file under `ios/LetsGo/` needs no project edit. Change build settings in `project.yml`, then run `xcodegen generate` and commit both.
- Bundle id `com.yasser100ali.letsgo`, team `X3HMA23KKN` (same Apple team as Pulse).

## Rules
- Weeks start Monday if anything ever needs a calendar week.
- MVVM-ish: views stay dumb; logic that can be tested lives in plain types (`Wren`, `WrenQuery`, `Pricing`, `Walk`).
- Every write goes through `Ledger` so stamps and Wren's taste notes stay consistent. Saves log on failure, never silently.
- Anything shown as a real person, place or listing that isn't one must be marked Sample.
- Tests use Swift Testing (`import Testing`), not XCTest.
- Never commit the App Store Connect key (`*.p8`, `asc_api_key.json`).

## Ship
From GitHub: `gh workflow run ios-cd.yml -R yasser100ali/lets-go` (tests, archive, sign, upload, wait for processing) on the Mac mini's `letsgo` runner. Locally: `scripts/ship.sh`. Either way the build number is App Store Connect's highest + 1, so nothing is committed. Internal testers get every build. Only ship when asked for a build.
